# ПОСЛЕДНИЙ СТРАЖ — дизайн-документ (GDD)

> Рабочее название. Ориентир по жанру — мобильные экшен-RPG от первого лица
> с вертикальным экраном и свайп-боем (например, Path of Kings). Мы берём
> **жанр и тип управления**, но не копируем чужой мир, персонажей, арт, звук
> и интерфейс. Все ассеты — свои.

## Суть
Королевство пало за одну ночь: Пепельная Корона расколола небо, и мёртвые
встали в своих доспехах. Игрок — последний Страж Зари. С фонарём-реликвией
он идёт от разрушенной заставы к столице, комната за комнатой, чтобы
вернуть рассвет.

**Жанр:** экшен-RPG / роглайт от первого лица, вертикальный экран, одна рука.
**Сессия:** забег 3–5 минут, полный акт 20–30 минут.

## Столпы дизайна
1. **Бой на свайпах, который читается.** Враг всегда показывает, откуда бьёт.
   Ты проигрываешь из-за своей реакции, а не из-за случайности.
2. **Одна рука, вертикальный экран.** Всё управление — большим пальцем в нижней трети.
3. **Каждый забег что-то даёт.** Даже проигрыш приносит ресурсы и знания.
   Нет «пустых» боёв — главная жалоба игроков на жанр.
4. **Короткие решения между боями.** Развилки пути выбираются свайпом карточки.
5. **Честная монетизация.** Реклама только по желанию игрока, без давления в бою.

## Основной цикл
```
Застава (хаб) → выбор героя и снаряжения → забег по локации
   → комнаты: бой / сундук / алтарь / торговец / событие
   → развилки (свайп карточки влево/вправо)
   → босс → награда → Застава: крафт, улучшения → следующий забег
```

## Управление
| Жест | Действие |
|---|---|
| Свайп в сторону подсвеченного слабого места | Удар (влево / вправо / вверх — сверху) |
| Свайп **против** направления замаха врага | Парирование, окно 0.25 с; удачное — оглушение |
| Свайп вниз | Блок щитом (тратит стойкость) |
| Двойной свайп в сторону | Уклонение-перекат (неуязвимость 0.3 с) |
| Тап по иконке умения (3 слота) | Способность класса, перезарядка |
| Удержание пальца | Заряженный удар (×2.5 урона, оставляет открытым) |
| Свайп карточки пути | Выбор развилки: влево — одна дорога, вправо — другая |
| Переключатель «Автобой» | Для фарма пройденных комнат; в новых комнатах и на боссах выключен |

Все жесты распознаются в нижних 45% экрана, верх остаётся под обзор.

## Бой
- **Враг по одному в кадре** (максимум 2–3 в волне по очереди). Камера смотрит на текущего.
- **Телеграф:** перед ударом враг замахивается 0.6–1.0 с, сторона удара
  подсвечивается красным свечением оружия и стрелкой по краю экрана.
- **Стойкость врага:** парирования и попадания в слабое место ломают её →
  оглушение 2 с, урон ×2.
- **Стойкость игрока:** блоки и перекаты тратят её, она восстанавливается со временем.
- **Комбо:** 3 точных удара подряд дают «Искру», следующее умение срабатывает усиленным.
- Урон, время замаха и окна парирования хранятся в JSON, чтобы автоигрок
  и баланс читали одно и то же.

## Классы (на старте)
| Класс | Стиль | Умения |
|---|---|---|
| **Страж** (воин) | медленно, сильно, щит | Удар щитом (оглушение), Боевой клич (+броня), Сокрушение (по площади) |
| **Тень** (плут) | быстро, крит, перекаты | Метательный нож, Шаг в тень (увернуться и зайти за спину), Яд |
| **Пламенник** (маг) | дистанция, заряд | Огненный шар, Ледяная стена (замедляет замах врага), Цепная молния |

Класс выбирается на Заставе, открывается прохождением первого акта.

## Враги (акт 1)
- **Пепельный мертвец** — базовый, удары слева/справа.
- **Щитоносец** — блокирует удары спереди, бить только после его атаки.
- **Летучий нетопырь** — быстрые атаки сверху, мало здоровья.
- **Шаман пепла** — лечит других, его бьют первым.
- **Босс: Рыцарь Без Лица** — 3 фазы, комбинации из 2–4 ударов, фаза ярости.

## Локации
1. **Застава Зари** — хаб: кузница, алтарь умений, сундук, доска заданий.
2. **Проклятый лес** (акт 1) — туман, светящиеся грибы, корни.
3. **Руины замка** (акт 2) — разбитые витражи, лунный свет.
4. **Огненные копи** (акт 3) — лава, жар, раскалённая руда.

Забег генерируется из готовых комнат-модулей (8–12 комнат + босс).

## Прогрессия
- **Уровень героя** растёт за опыт забегов: +здоровье, +урон.
- **Снаряжение:** оружие, щит/фокус, шлем, броня, 2 кольца. Редкости:
  обычное → редкое → эпическое → легендарное.
- **Крафт:** осколки и самоцветы из забегов → кузница: создать, улучшить, вставить самоцвет.
- **Алтарь умений:** дерево пассивных талантов для каждого класса.
- **Сила отряда** (одно число) — понятная формула, показана в подсказке.
- **Награды:** гарантированная награда за каждую комнату и стабильный рост
  наград к концу забега, чтобы не было жалоб «за победу ничего не дают».

## Арт
- **Стиль:** стилизованное низкополигональное 3D в мрачном фэнтези,
  выразительные силуэты, «рисованные» текстуры с крупными мазками.
- **Свет:** тёмная сцена + тёплые акценты (фонарь, огонь, магия) и холодный
  туман. Запечённое освещение, без динамических теней на слабых устройствах.
- **Камера:** от первого лица, видны руки и оружие героя, лёгкое покачивание.
- **Палитра по актам:** лес — сине-зелёный + янтарь; замок — фиолетово-серый + лунно-белый;
  копи — чёрный + оранжево-красный.
- **Интерфейс:** вверху здоровье врага и его стойкость, внизу полоски
  здоровья/стойкости игрока и 3 кнопки умений, крупные и контрастные.
- **Ассеты:** свои модели (Blender) или свободные паки под CC0 с указанием
  источника. Никаких извлечённых из чужих игр файлов.
- До готового арта — серые болванки (примитивы) с цветовой кодировкой.

## Звук
- Сочный звук попадания, отдельный «звон» для парирования, гул перед ударом босса.
- Хаптика: короткий импульс на попадание, двойной на парирование, длинный на получение урона.

## Технологии
- Godot 4.3, 3D, рендерер **GL Compatibility** (широкий охват Android).
- Портретная ориентация, внутреннее разрешение 540×960 с масштабированием.
- Бюджет: 60 FPS на среднем Android 2022 года, ≤ 60k треугольников в кадре,
  ≤ 50 draw calls, текстуры ETC2/ASTC, одна комната в памяти + следующая подгружается.
- Данные (враги, оружие, комнаты, награды) — в JSON в `data/`.
- Автоигрок `tools/autoplay.gd`: проходит первый забег без людей, код выхода 0.

## Монетизация (план)
- Бесплатно, без энергии и таймеров на вход в забег.
- Реклама **только по желанию**: удвоить награду, воскреснуть один раз за забег.
- Разовая покупка «Без рекламы» (дающая эти бонусы без просмотра).
- Косметика: облики оружия и фонаря.
- Без лутбоксов и платных предметов, которые сильнее бесплатных.
